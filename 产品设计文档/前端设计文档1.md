下面这版方案的核心目标是：**不再继续扩展“章节页面”，而是把当前已有能力全部收束成一个以星球为中心的沉浸式前端系统**。当前 demo 里已经有“我的星系、隐私星域、纪念星域、星球工坊、记忆星群、共鸣星轨、主题星云、家书工坊”等并列入口，且星球点击主要进入右侧信息面板，家书/主题/记忆也仍然偏页面化和表单化，这是下一版需要重构的主要问题。(jiashu_planet_galaxy_v4_demo.html) (jiashu_planet_galaxy_v4_demo.html) (jiashu_planet_galaxy_v4_demo.html)

# 一、v7.4 的产品范式

## 从“功能型 App”改成“星球漫游游戏”

用户进入后看到的不是菜单，而是一个正在运行的家庭星系。

产品主体验变成：

> 自动巡航星系  
> 靠近星球  
> 打开星球操作环  
> 进入星球表面  
> 探索记忆地貌  
> 点亮/挖掘/连接记忆星  
> 生成家书或星册

所有功能都不再以章节入口暴露，而是附着在四类对象上：

| 核心对象 | 产品职责                                                     | 不再承担的职责         |
| -------- | ------------------------------------------------------------ | ---------------------- |
| 星球     | 人、纪念对象、关系主题；承载身份、生命周期、主题、权限、成长状态 | 不再只是详情卡片       |
| 记忆星   | 单个事件、照片、语音、故事、时间点                           | 不再是列表项或表单记录 |
| 星轨     | 星球之间的关系、共鸣、共同记忆、多人视角                     | 不再是单独章节页面     |
| 星云     | 主题、风格、语气、背景、生成模板                             | 不再是主题卡片列表     |

家书是结果，不是一级概念。它从星球、星轨、记忆星、星云自然生成。

# 二、三层体验架构

## 第一层：全屏星系

这是首页，也是默认状态。

### 目标

解决用户的第一个问题：

> “我在哪里？我可以探索什么？”

### 关键变化

当前 demo 已经有星系拖拽、缩放、旋转和推荐航线，但它仍然有明显的左侧章节目录、顶部按钮和页面切换感。下一版应该改成：

- 默认全屏。
- 自动巡航默认开启。
- 左侧目录隐藏，只保留一个极小的“星图菜单”按钮。
- “我的星系 / 隐私星域 / 纪念星域 / 记忆星群 / 共鸣星轨 / 主题星云 / 家书工坊”全部变成星系图层、对象状态或操作。
- 顶部按钮减少为 3 个：`星图菜单`、`自动巡航`、`点亮记忆`。
- 右下角保留镜头控制，但默认半透明，只有鼠标靠近时出现。

### 全屏星系界面结构

```text
┌────────────────────────────────────────────┐
│  家书星球 Logo                     星图菜单 │
│                                            │
│       自动巡航中的家庭星系                 │
│                                            │
│   妈妈星球       共鸣星轨        爸爸星球  │
│                                            │
│          我的星球                          │
│                                            │
│     外婆纪念星        公开旅行星           │
│                                            │
│ 星图助手提示              镜头控制/退出巡航 │
└────────────────────────────────────────────┘
```

### 星系中显示什么

星系不再按章节切换，而是显示一个完整宇宙：

- 家庭成员星球
- 纪念星球
- 公开星球
- 关系星轨
- 共鸣星轨
- 记忆星尘
- 主题星云背景
- AI 星图助手提示
- 未完成任务光点

当前“记忆星群”和“共鸣星轨”已经在 demo 中分别作为独立 screen 存在，并且通过光点、轨道、两颗星球之间的连接来表达记忆和共鸣；下一版应把这些视觉元素统一叠加到首页星系，而不是继续保留独立页面。(jiashu_planet_galaxy_v4_demo.html) (jiashu_planet_galaxy_v4_demo.html)

## 第二层：星球操作环

这是用户悬浮或点击星球后的核心交互层。

### 目标

解决用户的第二个问题：

> “我能对这颗星球做什么？”

### 触发方式

桌面端：

- 悬浮星球 300ms：显示轻量操作提示。
- 单击星球：镜头飞近，星球放大，打开操作环。
- 双击星球：直接进入星球表面漫游。
- 右键 / 长按：打开高级操作环。

移动端：

- 轻点星球：打开操作环。
- 长按星球：打开编辑/权限/主题操作。
- 双指缩放：调整星系镜头。

### 操作环结构

操作环不是普通菜单，而是围绕星球出现的径向能力层。

```text
                 生成家书
                    ↑
       改主题 ←  星球  → 设置权限
                    ↓
              进入星球
        点亮记忆       设置生命线
```

### 操作环动作定义

| 动作       | 说明                     | 交互形式                       |
| ---------- | ------------------------ | ------------------------------ |
| 进入星球   | 进入星球表面漫游         | 镜头穿越星环，进入星球地貌     |
| 点亮记忆   | 快速记录一句话/语音      | 在星球表面生成一颗暗星，再点亮 |
| 改主题     | 修改星球风格、天气、材质 | 拖一片星云覆盖星球             |
| 设置权限   | 设置星球/记忆可见范围    | 调整光照圈，或拖动记忆星到轨道 |
| 设置生命线 | 设置出生、阶段、纪念时间 | 拖动星球外侧生命轨道节点       |
| 生成家书   | 从该星球生成家书         | 星球光线收束为纸张/书页        |

### 根据星球类型动态变化

不同星球的操作环不完全一样。

#### 我的星球

- 进入星球
- 点亮记忆
- 改主题
- 设置权限
- 查看收到的记忆星
- 生成我的生命家书

#### 妈妈/爸爸星球

- 进入星球
- 邀请补充
- 点亮关于 TA 的记忆
- 查看共鸣星轨
- 生成给 TA 的家书
- 请求查看更多内容

#### 孩子星球

- 进入成长星球
- 点亮成长瞬间
- 添加作品/照片
- 写给未来的信
- 生成成长册

#### 纪念星球

- 进入纪念星
- 补充一段回忆
- 查看传承星轨
- 设置生命周期
- 生成纪念星册

#### 公开旅行星

- 查看公开星册
- 添加地点记忆
- 调整公开范围
- 生成旅行长图/星册

# 三、星球内部漫游设计

## 1. 星球内部场景结构

进入星球后，用户看到一个大星球占据屏幕中心。星球可以旋转、缩放、深入。

```text
┌────────────────────────────────────────────┐
│ 返回星系              妈妈的星球   1968—现在 │
│                                            │
│              可旋转星球表面                │
│        春节山谷 / 厨房火光 / 旅行海岸       │
│                                            │
│    记忆星      暗区      共鸣虫洞          │
│                                            │
│  时间轨道：年轻时 —— 成家 —— 现在          │
│                                            │
│ 星图助手：这里有一段未完成的春节记忆        │
└────────────────────────────────────────────┘
```

## 2. 星球表面地貌

不同主题不只是换颜色，而是改变“地貌”。

| 星球类型 | 地貌设计                       | 记忆呈现                         |
| -------- | ------------------------------ | -------------------------------- |
| 我的星球 | 蓝白薄雾、静海、透明环         | 私密光点、日记碎片、低亮度暗星   |
| 父母星球 | 暖橘山谷、旧照片颗粒、厨房火光 | 饭桌、老照片、语音波纹           |
| 孩子星球 | 明黄草地、涂鸦轨迹、糖果卫星   | 成长里程碑、作品碎片、生日光点   |
| 纪念星球 | 紫灰石碑、银白星尘、慢速光雨   | 生命周期节点、家人寄语、传承光束 |
| 旅行星球 | 青绿海岸、地图线、日落环       | 地点光标、照片流星、路线轨迹     |

## 3. 时间轨迹

不要再用列表展示时间。时间变成围绕星球的轨道。

- 外层轨道：人生阶段。
- 中层轨道：家庭共同时刻。
- 内层轨道：个人私密记忆。
- 发光节点：已确认记忆。
- 暗淡节点：AI 待确认线索。
- 闪烁节点：家人邀请补充。
- 断裂节点：缺失年份或未完成采访。

用户可以拖动时间节点：

- 调整年份。
- 合并相近记忆。
- 把某段记忆拖到家庭可见轨道。
- 把某段记忆拖到家书生成轴。

## 4. 记忆星交互

记忆星是星球表面的核心可玩点。

### 记忆星状态

| 状态   | 视觉           | 含义                 |
| ------ | -------------- | -------------------- |
| 暗星   | 微弱光点       | 有素材但未整理       |
| 半亮星 | 柔光脉冲       | AI 已整理，待确认    |
| 亮星   | 稳定发光       | 已确认记忆           |
| 共鸣星 | 外圈有星轨波纹 | 与其他星球有共同记忆 |
| 纪念星 | 银紫色慢光     | 与已故成员相关       |
| 公开星 | 有外层光环     | 可分享或已成册       |

### 记忆星操作

- 点击：进入故事场景。
- 悬浮：显示时间、人物、情绪。
- 拖动：改变时间或权限轨道。
- 长按：补充一句话。
- 拖到另一颗记忆星：尝试合并。
- 拖到另一个星球方向：创建共鸣候选。
- 拖到“家书光束”：加入家书素材。

# 四、故事场景设计

故事场景是星球内部的第三深度状态，但仍属于“星球内部漫游”，不是新章节。

## 进入方式

点击某颗记忆星。

## 场景结构

```text
┌────────────────────────────────────────────┐
│ 返回星球       新家里的第一个除夕           │
│                                            │
│       漂浮照片碎片      语音光波            │
│                                            │
│  时间：2018 除夕                            │
│  地点：新房客厅                             │
│  人物：妈妈、我、孩子                       │
│  情绪：团圆、疲惫、安定                     │
│                                            │
│  补充一句话   邀请家人   加入家书   设权限   │
└────────────────────────────────────────────┘
```

## 视觉

- 照片像漂浮碎片。
- 语音像扩散的声波。
- AI 提取的信息变成星尘标签。
- 记忆原文不是 textarea，而是“故事石碑”或“光幕”。
- 家人补充内容像不同颜色的轨迹靠近同一颗记忆星。

## 操作

| 操作         | 体验表达                           |
| ------------ | ---------------------------------- |
| 补充一句话   | 点亮一颗小卫星，围绕当前记忆星旋转 |
| 邀请家人     | 发射一束光到对方星球               |
| 加入家书     | 记忆星飞入“家书光束”               |
| 设置权限     | 把记忆星拖到私密/家庭/公开轨道     |
| 查看来源     | 展开照片、语音、文字来源碎片       |
| 确认 AI 摘要 | 用“确认点亮”替代表单提交           |

# 五、四类核心对象的职责边界

## 1. 星球

星球负责“人和身份”。

### 承载内容

- 名称
- 头像/星球外观
- 类型：自己、父母、孩子、纪念、公开主题
- 生命周期
- 主题风格
- 权限默认值
- 记忆数量
- 共鸣数量
- 成长状态
- AI 任务状态

### 不能做什么

星球不直接承载具体故事正文。具体故事属于记忆星。

---

## 2. 记忆星

记忆星负责“单个事件”。

### 承载内容

- 时间
- 地点
- 人物
- 照片
- 语音
- 文字
- 情绪
- 来源
- 权限
- AI 摘要
- 是否加入家书
- 是否与其他星球共鸣

### 不能做什么

记忆星不直接定义主题风格。主题风格属于星云或星球。

---

## 3. 星轨

星轨负责“关系和连接”。

### 承载内容

- 两颗或多颗星球之间的关系
- 同一天的多视角记忆
- 亲子、夫妻、家族、旅行、纪念等关系类型
- AI 共鸣解释
- 双方确认状态
- 可生成的家书方向

### 不能做什么

星轨不替用户决定故事真相。它只提出连接，是否确认由家人完成。

---

## 4. 星云

星云负责“风格和生成语气”。

当前 demo 已经有亲子成长、父母人生、纪念星云、家庭团圆、旅行星云、伴侣星云等主题卡片；下一版应保留这些主题能力，但从“主题页面”变成可拖拽、可覆盖、可收藏的星云对象。(jiashu_planet_galaxy_v4_demo.html)

### 承载内容

- 背景色
- 星球材质
- 地貌风格
- AI 采访问题
- 家书章节模板
- 生成语气
- 动效风格

### 不能做什么

星云不直接代表某个家庭成员，也不承载具体记忆。

# 七、核心交互流

## 流程一：第一次进入产品

```text
进入产品
→ 自动巡航打开
→ 镜头慢慢经过家庭星系
→ 星图助手提示“靠近妈妈的星球看看”
→ 用户点击妈妈星球
→ 镜头飞近，操作环出现
→ 用户选择“进入星球”
→ 进入妈妈星球表面
→ 看到春节山谷、旅行海岸、外婆菜谱光点
→ 点击春节记忆星
→ 进入故事场景
→ 补充一句话
→ 记忆星变亮
→ 共鸣星轨增强
→ 提示可生成一页家书
```

## 流程二：点亮一颗记忆星

```text
全屏星系
→ 点击“点亮记忆”
→ 鼠标变成一颗暗星
→ 拖到妈妈星球附近
→ 释放
→ 出现语音/一句话输入浮层
→ 用户说一句话
→ AI 生成半亮记忆星
→ 用户确认
→ 星球表面新增光点
→ 如果识别到共同时间，星轨出现微光
```

这里的输入浮层要非常轻，不像表单：

- 一句话输入
- 语音按钮
- 添加照片
- 确认点亮

高级字段隐藏到“星尘标签”里。

## 流程三：设置权限

```text
进入星球
→ 选中一颗记忆星
→ 出现三层轨道：私密 / 家庭 / 公开
→ 拖动记忆星到对应轨道
→ 光照范围变化
→ 星图助手提示“这颗记忆现在仅家庭可见”
```

权限从开关变成空间位置。

## 流程四：修改主题

```text
点击星球
→ 操作环选择“改主题”
→ 星系边缘浮现几片星云
→ 拖“纪念紫星云”覆盖外婆星球
→ 星球材质、背景、光效、AI 语气同步变化
```

主题从选择卡片变成“给星球上色”。

## 流程五：生成家书

```text
选择一颗星球 / 一条星轨 / 多颗记忆星
→ 拖入“家书光束”
→ 选择星云语气
→ 预览家书
→ 分享前确认权限
→ 家书变成一颗收藏星，回到星系中
```

当前 demo 的家书工坊已有“选择单星球、双星系、家庭星系、纪念星”等来源，这个能力可以保留，但不再以表单页面呈现，而是通过框选、拖拽和星轨收束完成。(jiashu_planet_galaxy_v4_demo.html)

# 八、样式主题设计

## 全局视觉基调

整体基调仍然可以保留当前 demo 的暗场、星尘、玻璃拟态、暖金/珊瑚/蓝灰等颜色基础，但要增强不同对象的差异化。

### 全局色彩变量

## 星球主题

### 我的星球：静海蓝星

- 背景：蓝白薄雾、低饱和星尘。
- 星球：半透明水晶感。
- 星环：细、慢、偏蓝。
- 记忆星：小而克制。
- 动效：慢速呼吸，自转很轻。
- 情绪：安静、整理、自省。

### 父母星球：暖橘家书星

- 背景：暖橘、米金、旧照片颗粒。
- 星球：釉面、柔和高光。
- 星环：像饭桌热气一样轻微摆动。
- 记忆星：偏暖，带脉冲。
- 动效：像烛火一样微闪。
- 情绪：家庭、人生、讲述。

### 孩子星球：明黄成长星

- 背景：明黄、浅绿、柔糖果色。
- 星球：更圆润、更亮。
- 星环：涂鸦线、彩色轨迹。
- 小卫星：作品、照片、生日。
- 动效：轻微弹跳。
- 情绪：成长、未来、第一次。

### 纪念星球：银紫纪念星

- 背景：紫灰、银白、低饱和。
- 星球：石纹、星尘、轻雾。
- 星环：慢速、像钟摆。
- 记忆星：银紫光，不刺眼。
- 动效：星尘缓慢下落。
- 情绪：克制、传承、安静发光。

### 公开旅行星：青绿旅行星

- 背景：青绿、日落金、地图线。
- 星球：带地形纹理。
- 星环：路线飞线。
- 记忆星：照片流星、地点锚点。
- 动效：轨迹流动。
- 情绪：开放、分享、远方。

# 九、动效设计

## 1. 全屏星系巡航

自动巡航不是简单旋转，而是镜头路径。

```text
远景：整个家庭星系
→ 中景：我的星球与父母星球关系
→ 近景：妈妈星球旁的记忆光点
→ 拉远：共鸣星轨发光
→ 转向：纪念星球慢慢进入画面
```

巡航过程中，用户一旦拖拽或滚轮，自动巡航暂停。3 秒无操作后出现“继续巡航”提示。

## 2. 靠近星球

点击星球后：

- 其他星球轻微暗化。
- 目标星球放大到屏幕中心。
- 星轨线向目标星球收束。
- 操作环从星环上生长出来。
- 背景星云切换为该星球主题色。

## 3. 进入星球

从操作环点击“进入星球”：

- 镜头穿过星环。
- 星球表面从圆形变成可探索地貌。
- 时间轨道从星球外环展开。
- 记忆星从表面浮起。
- AI 星图助手以一句轻提示出现。

## 4. 点亮记忆

用户确认记忆后：

- 暗星闪烁三次。
- 光点扩散到地表。
- 对应时间轨道出现刻度。
- 如果存在共鸣，远处另一颗星球回应一道微光。
- toast 改成“星图事件反馈”，例如：“妈妈的春节山谷多了一颗新星”。

## 5. 生成家书

生成时不要立即跳页面：

- 被选中的记忆星依次飞出。
- 星轨汇聚成一束光。
- 光束折叠成纸张。
- 家书预览像书页从星光中展开。
- 完成后，家书变成一颗“收藏星”回到星系。

# 十三、AI 星图助手设计

AI 不再是“生成按钮”，而是一个宇宙里的向导。

## 出现场景

- 用户第一次进入星系。
- 巡航经过发光记忆。
- 检测到共鸣星轨。
- 用户进入星球暗区。
- 用户准备生成家书。
- 用户调整权限时。

## 提示形式

不要用大段说明。用短句、低打扰、可操作：

- “妈妈的春节山谷有一颗半亮记忆，靠近看看？”
- “你和妈妈都提到 2018 除夕，可能形成一条共鸣星轨。”
- “这颗记忆目前仅自己可见，拖到家庭轨道即可邀请家人补充。”
- “外婆的菜谱照亮了妈妈星球的一片区域，可以写成传承页。”
- “已选中 4 颗记忆星，可以收束成一页家书。”

## AI 可视化

- AI 发现线索：淡金色扫描波。
- AI 共鸣候选：虚线星轨。
- AI 已确认内容：稳定星轨。
- AI 待补充内容：雾区或暗星。
- AI 生成中：光束收束动画。

# 十四、游戏化成长机制

为了高可玩性，需要让星球“真的变”。

## 星球成长

| 用户行为     | 星球变化             |
| ------------ | -------------------- |
| 点亮一颗记忆 | 星球表面新增光点     |
| 补充照片     | 生成照片碎片地貌     |
| 补充语音     | 生成声波环           |
| 确认共鸣     | 两颗星球之间星轨变亮 |
| 完成生命周期 | 星球外环补全         |
| 生成家书     | 星球获得收藏星       |
| 家人补充视角 | 星球出现外来小卫星   |
| 设置主题     | 地貌、星云、粒子变化 |

## 轻任务系统

任务不叫任务，可以叫“星图提示”或“待点亮”。

例子：

- “妈妈星球还有 3 颗暗星未确认”
- “爸爸的旅行海岸缺少一张照片”
- “外婆纪念星有一条传承星轨待补充”
- “孩子星球可以生成第一本成长册”
- “你和妈妈的春节记忆可以写成家书”

# 十五、v7.4 最小可实现范围

下一版不要一口气实现所有复杂逻辑，建议 v7.4 先完成前端范式重构。

## 必做

1. 首页默认全屏星系，自动巡航默认开启。
2. 左侧目录隐藏，只保留“星图菜单”。
3. 所有旧章节入口改成图层开关。
4. 悬浮/点击星球出现操作环。
5. 点击“进入星球”进入真正的星球内部场景。
6. 星球内部有：可旋转星球、时间轨道、记忆光点、暗区。
7. 点击记忆星进入故事场景。
8. 点亮记忆后，星球表面新增光点。
9. 改主题从卡片选择改成星云覆盖效果。
10. 生成家书从独立页面改成“星球/星轨/记忆星收束成家书”。

## 可以暂时 mock

- 多人权限真实逻辑。
- AI 真实分析。
- 语音真实录入。
- 家书真实生成。
- 数据持久化。
- 多用户协同。

## v7.4 验收标准

- 用户不需要点击左侧章节，也能完成“进入星球 → 查看记忆 → 补充一句话 → 生成家书”。
- 用户点击任何星球都能看到该星球专属操作，而不是统一详情面板。
- 星球内部不再像信息预览页，而像一个可探索空间。
- 主题、权限、生命周期、生成家书都能从星球操作环进入。
- 记忆星、星轨、星云在视觉和职责上清晰区分。
- 不同星球类型的颜色、动效、地貌明显不同。
