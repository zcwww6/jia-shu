# 家书星球当前项目状态

**更新时间**：2026-07-28

**当前可演示版本**：旧版沉浸式家书 MVP，分支 `feat/legacy-family-mvp`，工作树 `.worktrees/legacy-family-mvp`
**固定入口**：[http://localhost/galaxy](http://localhost/galaxy)

本文是旧版 MVP 的工程、部署、真实能力边界与验收依据。带日期的旧进展快照和已替代方案仅保留历史价值，不得据此判断当前实现。

## 一句话产品故事

家庭管理员先为家人创建一颗星球；在星球漫游中留下文字、日记、语音或照片来源；经本人授权与确认后，记忆成为可见的记忆星；两颗星球的真实记忆形成可确认的共鸣星轨；管理员再用被授权的来源生成、编辑和分享一封家书。原始私密素材始终留在私密媒体库，公开的是经过确认的派生记忆和家书快照，而不是原文件。

## 当前运行状态

- 本机 Docker Compose 运行 `postgres`、一次性 `migrate`/`media-init`、`app`、`worker` 和 `nginx`。
- Nginx 固定绑定 `127.0.0.1:80`；App 与 PostgreSQL 不向宿主机发布端口。
- PostgreSQL 与媒体使用 named volume；日常重启或 `docker compose down` 不加 `-v` 均不会删除数据。
- 2026-07-28 已重建旧版 `app` 和 `worker` 镜像；`/api/health/live` 与 `/api/health/ready` 返回 `200`，未登录访问 `/galaxy` 正常跳转登录（`307`），Nginx、App、PostgreSQL 为 healthy。
- 不使用云服务器、云 RDS、Vercel KV、local JSON 或 Mock 作为业务主存储。

## 真实数据与可点击操作

`/galaxy` 是唯一业务工作台。已登录账户读取 `getHomeData` 的 PostgreSQL 投影；空账户保持空星系，不自动填充示例家庭。

### 已真实写入数据库的操作

| 场景 | 用户动作 | 服务端事实 |
| --- | --- | --- |
| 家庭星系 | 创建家人星球、重命名、改主题、改权限、设为纪念/在世、归档、恢复 | `/api/planets`、`/api/planets/:id`、`/restore`；版本校验后写入 Planet |
| 星环与星图 | 新增家庭连接、自定义星轨、归档/恢复星球 | `/relationships` 与 Planet 归档记录；刷新后按真实关系投影 |
| 星球工坊 | 上传封面并保存 | 私密 `MemoryAsset` 上传后以 `coverAssetId` 写回 Planet；原图不被家庭公开 |
| 点亮记忆星 | 文字、日记文件、语音或图片来源，授权 AI，编辑并确认 | Asset/Memory/AI Job 均写入 PostgreSQL；只有 `confirm` 后进入主星系 |
| 共鸣星轨 | 扫描候选、确认或拒绝 | Resonance 记录和版本状态由服务端保存；确认后投影为真实连线，并在刷新/重新登录后恢复为可生成家书的真实来源 |
| 家书工坊 | 生成、打开、编辑、创建分享、撤回分享 | `Book`、来源授权、Share 快照和撤回状态均由服务端保存 |

### 合理但不写库的浏览动作

旋转、缩放、拖拽、自动巡航、沉浸模式、长辈模式、面板开关、星图关系类型筛选与材质预览只改变当前浏览。界面明确标注“仅本次浏览”，不伪装为保存。它们不改变家庭故事，也不应写入数据库。

### 不再作为业务回退的数据

- `shared/mock/galaxy-data` 和静态星区文案只服务视觉布局、引导和组件测试。
- 示例共鸣候选、示例家书、浏览器本地草稿均不会在真实业务路径中替代服务器结果。
- 历史独立入口 `/planet/:id`、`/themes`、`/memory/new`、`/resonance` 与 `/books/new` 已统一收束至 `/galaxy`，避免用户落入旧 Mock 页面。

## AI 与素材边界

### 已验证可用

- 文本和日记/文档：提取真实文字后由已配置的兼容 OpenAI 服务整理；AI 结果必须由用户确认。
- 图片：通过已配置的视觉模型读取经授权的私密图片，生成待确认的派生记忆；原图继续维持私密。
- 语音：若配置 `OPENAI_TRANSCRIPTION_MODEL`，使用标准 `/audio/transcriptions`；未配置时，使用已验证的 `OPENAI_MODEL` 音频对话输入并以严格 JSON 返回转写。当前凭证下后者已通过真实匿名 WAV 请求验证。
- 共鸣解释与家书生成：调用真实文本模型；未配置或上游失败时返回安全错误，绝不伪造生成结果。
- 原始图片、音频和文档均以私密媒体文件保存；经明确同意后可生成家庭可见的派生记忆，原始文件本身不会扩大可见范围。

### 配置缺失时的行为

- 图片整理需要 `OPENAI_VISION_MODEL`；语音整理需要可访问的转写模型或支持音频输入的 `OPENAI_MODEL`。任一能力缺失时，系统明确返回安全配置错误，不会伪造记忆或生成结果。
- 当前本地 Docker 凭证已对图片、日记、语音、共鸣和家书执行过真实闭环验收；凭证变更后必须重新执行下方的真实验收命令。

## 关键闭环与安全约束

1. 所有写接口均经过 Auth.js 身份识别和个人星系作用域检查，不能跨用户读写。
2. 星球、记忆、共鸣与家书的并发修改使用版本号；创建类操作使用幂等键。
3. 素材上传对相同幂等键进行指纹校验；失败上传只允许一位调用者原子地接管重试，避免重复资源或覆盖写入。
4. AI 作业在用户同意时冻结记忆与素材快照；内容或权限变化会使旧同意失效，Worker 不再发送旧素材。
5. 分享只读取服务端生成的快照，撤回后 token 立即失效。
6. 共鸣确认不是浏览器会话状态：首页读模型会恢复已确认来源，刷新后仍可进入家书工坊；生成接口仍会二次验证来源授权。
7. 隐私星域不再出现未落库的“允许 AI / 进入共鸣 / 公开原始素材”开关。AI、共鸣与家书授权均在记忆确认步骤逐条保存；外部公开只通过可撤回家书链接完成。

## 最终人工演示验收

以下步骤必须在已登录家庭管理员账户中使用可授权的测试内容完成；不要在未经授权时上传真实家庭私密素材。

1. 创建两颗家人星球，重命名其中一颗并建立一条连接；刷新页面确认仍在。
2. 向两颗星球各确认一条文字或日记记忆；再上传一段测试语音，确认 AI 转写、编辑和点亮流程。
3. 扫描并确认一条共鸣；用它生成家书，刷新后打开、编辑、创建分享并撤回分享。
4. 上传一张家庭管理员授权的封面图片，保存后刷新，确认星球表面仍使用该封面。
5. 上传一张经管理员授权的图片作为记忆来源，确认 AI 整理、编辑和点亮；刷新后确认原图仍未以家庭公开素材形式暴露。
