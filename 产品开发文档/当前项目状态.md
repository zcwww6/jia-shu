# 家书星球当前项目状态

**更新时间**：2026-07-28

本文是工程、部署、产品能力和后续工作的**唯一现状入口**。README 仅说明运行与运维；带日期的旧进展快照和已替代方案仅作历史记录，不作为当前操作或规划依据。任何新说明都必须以当前路由、服务和数据库模型为准。

## 主线与分支

- `develop` 是当前集成主线。
- `main`、`master` 和 `test` 仍是早期发布基线；待主线稳定后，按流程由 `develop` 进入 `test` 再决定发布分支。
- 已完全合并的旧 `feature/*` 分支会在本阶段验证完成后清理。

## 当前部署

项目采用本地 Docker Compose：Nginx、Next.js standalone、一次性 Prisma migration 和 PostgreSQL 都在同一台机器上运行。

- Nginx 仅绑定 `127.0.0.1:80`；App 和 PostgreSQL 不发布宿主机端口。
- PostgreSQL 使用 named volume 持久化，备份与恢复按 README 的 `backups` 手册执行。
- OpenAI 与 Resend 都是可选的外部依赖；Magic Link 需要有效凭据和联网。
- 不使用云服务器、云 RDS、Vercel KV 或本地 JSON 作为主存储。
- 当前不支持 LAN 访问或 TLS；这两项需要单独设计与验收。

- Auth.js + Resend 提供登录入口和受保护路由。
- Prisma 7 + PostgreSQL 已覆盖用户、星系、星球、记忆、共鸣、家书、分享和认证模型。

## 当前可演示路径与受保护 API

`/galaxy` 是当前唯一业务入口；`/memory/new`、`/resonance`、`/books/new` 和 `/settings/privacy` 仅重定向回 `/galaxy`。以下是实际受保护的闭环，所有写操作按接口要求携带幂等键或版本：

1. `POST /api/memories` 创建已持久化的记忆草稿；随后以用户同意调用 `POST /api/memories/:memoryId/ai-jobs` 创建 AI 整理作业，并通过 `GET /api/ai-jobs/:jobId` 查询状态。
2. 用户在 `POST /api/memories/:memoryId/confirm` 确认整理结果。确认接口支持版本校验，业务记忆只在确认后进入后续流程。
3. `POST /api/resonances/scan` 以已确认记忆扫描候选；用户通过 `POST /api/resonances/:resonanceId/confirm` 作出带版本校验的决定。
4. `POST /api/books` 依据真实、可授权的记忆创建家书；`GET /api/books` 列表家书，`GET`/`PATCH /api/books/:bookId` 读取和编辑单本家书。
5. `GET`/`POST /api/books/:bookId/shares` 查看或创建分享快照，`POST /api/books/:bookId/shares/:token/revoke` 撤回分享；公开读取页为 `/share/:token`。

已退役的独立 demo API routes 已物理移除，不是当前路径，也不应被重新接入。

## 真实、视觉 Fixture 与外部边界

### 真实业务真相

- Auth.js 路由保护，以及 PostgreSQL/Prisma 中的用户、星系、星球、记忆、共鸣、家书和分享记录。
- 记忆 AI 作业、确认、共鸣决定、家书生成、版本与幂等处理均经受保护 API 和服务层执行。
- 分享 token 仅由服务端创建；分享快照和撤回状态由数据库保存。
- Docker、迁移、健康检查、持久化与备份恢复流程。

### 视觉 Fixture 与浏览器边界

- `shared/mock/galaxy-data` 中的星区、星球、记忆和故事节点只用于视觉展示与原型布局；其中不再提供共鸣候选或家书草稿作为业务回退。
- 前端如需保存纯视觉偏好，只能保存不影响业务结果的显示状态；记忆、共鸣、家书、分享、权限、版本和确认状态不得落入 `localStorage`，必须以服务端数据为准。
- 共鸣尚未接入向量检索；图片和语音仍待进一步产品化。

### 外部依赖

- OpenAI 为可选的 AI 作业提供方；其结果仍需经服务端确认流程写入业务模型。
- 真实 Resend Magic Link 需要有效凭据。

## 最近验证

- 已执行 Prisma generate。
- 当前验证记录为 90 个测试文件、702 个测试；lint 与生产 build 均通过。
- 主 Auth.js 处理器与 Edge middleware 已显式统一使用 JWT 会话策略，避免数据库会话 token 被 Edge 当作 JWE 解密；新会话不再写入 `Session` 表，历史记录保留但不参与认证，且当前不提供单会话服务端强制吊销；本地 App 更新后需清除 `localhost` 站点 Cookie 并申请新的 Magic Link，真实回调仍待手工验收。
