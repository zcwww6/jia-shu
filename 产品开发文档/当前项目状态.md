# 家书星球当前项目状态

**更新时间**：2026-07-13

本文是工程、部署、产品能力和后续工作的**唯一现状入口**。README 仅说明运行与运维；带日期的旧进展快照和已替代方案仅作历史记录，不作为当前操作或规划依据。已完成状态的本地 Docker 设计可作为当前实施设计与验收记录。

## 主线与分支

- `develop` 是当前集成主线。
- `main`、`master` 和 `test` 仍是早期发布基线；待主线稳定后，按流程由 `develop` 进入 `test` 再决定发布分支。
- 已完全合并的旧 `feature/*` 分支会在本阶段验证完成后清理。

## 当前部署

项目采用完全本地 Docker Compose：Nginx、Next.js standalone、一次性 Prisma migration 和 PostgreSQL 都在同一台机器上运行。

- Nginx 仅绑定 `127.0.0.1:80`；App 和 PostgreSQL 不发布宿主机端口。
- PostgreSQL 使用 named volume 持久化，备份与恢复按 README 的 `backups` 手册执行。
- OpenAI 可按需接入；未配置时回落到 Mock。Resend Magic Link 需要联网。
- 不使用云服务器、云 RDS、Vercel KV 或本地 JSON 作为主存储。
- 当前不支持 LAN 访问或 TLS；这两项需要单独设计与验收。

## 已完成工程能力

- Next.js 16 App Router、TypeScript 与 React 19 应用基础已落地。
- Auth.js + Resend 提供登录入口和受保护路由。
- Prisma 7 + PostgreSQL 已覆盖用户、星系、星球、分享和认证模型。
- 已提供 baseline migration、既有数据库采用门禁、升级前备份和恢复流程。
- 已提供 `live`/`ready` 健康检查。
- App 与 Migration 均以非 root 用户运行，Compose 使用有限日志和内部网络，Nginx 仅通过 loopback 对外暴露。

## 当前可演示路径

`/galaxy` 浏览 → 点亮记忆并调用 `/api/ai/extract` → 查看共鸣候选 → 生成家书草稿 → 确认分享并发布至 `/share/[token]` → 在另一浏览器检查分享边界。

- 登录用户发布、公开 token 分享。
- Docker、迁移、健康检查、持久化与备份恢复流程。

- 星系闭环仍混合 `localStorage`、前端状态和 API 演示逻辑。

### 外部依赖

- OpenAI 为可选外部能力。
- 真实 Resend Magic Link 需要有效凭据。

## 最近验证

- 已执行 Prisma generate。
- 当前验证记录为 22 个测试文件、76 个测试；lint 与生产 build 均通过。
- 主 Auth.js 处理器与 Edge middleware 已显式统一使用 JWT 会话策略，避免数据库会话 token 被 Edge 当作 JWE 解密；新会话不再写入 `Session` 表，历史记录保留但不参与认证，且当前不提供单会话服务端强制吊销；本地 App 更新后需清除 `localhost` 站点 Cookie 并申请新的 Magic Link，真实回调仍待手工验收。
- Compose 配置有效，PostgreSQL、App 和 Nginx 均为 healthy。
- `live`、`ready` 原始响应均为 200；未认证根路径原始响应为 307 并跳转至 `/sign-in`，跟随重定向后最终页面为 200。
- 空卷迁移、迁移幂等、命名卷持久化，以及真实备份恢复演练均已通过。
