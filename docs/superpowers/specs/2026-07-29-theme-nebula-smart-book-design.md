# 主题星云与智能家书设计

**日期：** 2026-07-29
**状态：** 已由产品负责人授权自行决策并实施
**范围：** 主题星云、家书阅读、文档来源、星球封面、演示数据与相关用户文案

## 产品决定

主题星云不再是通向同一个家书工坊的四个快捷方式，而是四种不同的家庭叙事策展台。用户先在星云里理解“这本书为什么值得被写”，查看适合的真实来源和智能编排建议，再主动选择装订。星球、星环、漫游和拖拽仍是空间主叙事；策展台只在进入主题星云后出现，不把产品改造成表单。

采用 A「家庭策展台」而不采用右侧任务表单或新增四个独立路由。它复用现有 themes 场景、/api/memories、/api/books 和私密资源流，避免在 10 天窗口内扩大导航、鉴权和状态恢复风险。

## 主题星云

亲子成长、父母人生、纪念星册、旅行星云各自显示：

- 一句非模板化的叙事承诺；
- 三类推荐来源及当前已选择的真实记忆；
- 一条“智能编排建议”，说明系统会如何组织素材而不代替家人判断；
- “上传一份家庭文档”与“开始装订家书”两个明确动作。

单击星云只选中并展开策展台，绝不切换到 books。只有点击“开始装订家书”才进入家书工坊并以该主题作为当前主题。已确认且允许写入家书的记忆可在策展台勾选；服务端仍是来源资格的唯一裁决者。

| 星云 | 叙事问题 | 推荐来源 | 家书范围 |
| --- | --- | --- | --- |
| 亲子成长 | 我们如何陪孩子长成自己？ | 第一次、成长照片、写给未来的话 | single_planet 或 family_galaxy |
| 父母人生 | 父母有哪些未被好好聆听的人生章节？ | 采访、旧日记、工作与成家照片 | family_galaxy |
| 纪念星册 | 如何让离开的家人继续被温柔地记住？ | 菜谱、手稿、声音、寄语 | memorial |
| 旅行星云 | 同一次远行被不同家人怎样记住？ | 路线、票据、照片、旅行日记 | family_galaxy |

## 智能文档到家书

首期接受 PDF、DOCX、Markdown、TXT；旧 .doc 入口移除并在帮助文案中说明“请另存为 DOCX 或 PDF”。继续使用已存在的安全边界：10 MiB、PDF 100 页、10 万抽取字符、DOCX ZIP/XML 检查、Mammoth 与 PDF.js。不得增加新的文档解析依赖。

流程固定为：上传原始文件（私密）→ 智能整理成待确认记忆 → 管理员编辑并确认记忆 → 该记忆回到当前主题的装订清单 → 管理员选择“开始装订” → /api/books 生成可编辑家书草稿 → 管理员校阅、保存或分享。

确认不是可选项：任何智能生成内容都不能绕过记忆确认直接保存或分享。后端已允许任何 confirmed 且 allowBook 的同星系记忆成为家书来源；前端移除“必须先确认共鸣才可写成文档家书”的额外限制，但保留共鸣入口作为另一种素材发现方式。

面向用户的文案统一使用“智能整理”“智能编排”“智能建议”“智能服务”，不出现“AI”。内部 API、作业类型和变量名不因本轮视觉文案改动而重命名。

## 家书阅读与校阅

阅读器继续采用暖纸双页和图文夹页。底部操作变为“上一页 / 下一页”，进度为“第 N / M 页”；每次操作仍展示一组双页，以保证现有 PDF 导出布局不变。

翻页由现有 Framer Motion 实现：向前从右页翻入、向后从左页翻回，使用 3D rotateY、x 和 opacity，时长 320–380ms。动画必须可中断，按钮不被动画锁死；键盘左右方向键在阅读器获得焦点后可翻页。prefers-reduced-motion 下改为短交叉淡入，不使用旋转。保留导出用的静态全书 DOM。

“装订校阅”在阅读页入口清楚表达：生成的是待管理员确认的草稿；编辑抽屉可继续修改标题、正文、图文顺序与分享范围。保存或创建分享链接前必须经由当前已有的编辑/分享权限链路。

## 星球工坊与封面

“给星球贴一张照片”改用显式按钮加 ref.current.click()，不再依赖被裁剪的原生 input 与 label 的隐式转发。文件选择后立即显示本地预览、可访问文件名与“保存星球封面”动作；保存仍写入受保护资产 API 和星球 coverAssetId。

前端和服务端接受范围对齐为 JPEG、PNG、WebP、AVIF。服务端 AVIF 验证和 Sharp 派生支持与上传声明同时加入；选择错误格式或超过限制时给出可恢复提示。

## 演示素材

为“林晚晴、沈知秋、林小满、外婆纪念星”演示家庭补充厨房暖灯、雨夜车灯、星空画、桂花糕手稿四张本地、版本化图片。图片通过受保护资产存储进入相应已确认记忆，并借由现有 BookMemory → MemoryAsset 映射显示在家书中；不使用外链图片或 public 裸资源。四颗演示星球同时各自获得一张封面。

图片素材必须是允许随仓库演示分发的原创或明确可再分发文件，并保留中性中文 caption 与 alt 文本。不得假称为真实用户照片。

## 非目标

- 不新增旧 .doc 解析；
- 不引入 react-pageflip、page-flip、officeparser 或运行时外部图库；
- 不为四个主题建立独立路由；
- 不改变数据库权限模型、原始文档私密性或分享默认值；
- 不把用户审核替换为自动发布。

## 验收标准

1. 四个主题星云均在原场景中展开不同的叙事与策展内容，选择主题不会跳转家书工坊。
2. 主题策展台可选择已确认记忆、发起文档整理，并仅在用户主动装订时进入家书工坊。
3. PDF/DOCX/MD/TXT 可走现有真实解析与确认链路；.doc 不再被前端接受，服务端拒绝保持安全。
4. 管理员确认后，单条或多条 allowBook 记忆可真实调用 /api/books 生成可编辑草稿。
5. 阅读器显示图文内容、上一页/下一页、方向翻页、键盘翻页与 reduced-motion 降级。
6. 星球封面按钮可靠打开文件选择器，JPEG/PNG/WebP/AVIF 前后端范围一致，预览与保存可用。
7. 种子数据在干净本地 Docker 数据库中创建带受保护图片的书和星球封面，浏览器登录后能完成端到端演示。
8. 相关单测、类型检查、lint、生产构建以及登录态浏览器验收通过。
